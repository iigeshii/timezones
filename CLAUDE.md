# Rules

- Never create a git commit without asking me first.
- Never push to a remote without asking me first.
- Commit messages: just the conventional summary line (e.g. `feat: ...`). No Co-Authored-By, Claude-Session, or other attribution lines.
- Work directly on `master`; don't create separate branches.
- Commit author and committer: `Gesh Giezel <geshgiezel@gmail.com>` (set `git config user.name`/`user.email` in the repo before committing).
